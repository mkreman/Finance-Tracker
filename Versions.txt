	- Export to PDF / CSV: While your JSON export is perfect for restoring app data, users often need their data in human-readable formats for taxes or sharing. Adding an option to export a specific month's transactions as a clean PDF report or a standard CSV file (readable in Excel/Google Sheets) is a highly requested feature in finance apps.
	- Allow users to snap a photo of a physical receipt or upload an invoice to attach directly to a transaction. This is incredibly useful for claiming business expenses, keeping track of warranties, or simply storing specific records like a vet bill for your cat or a receipt for bike maintenance. You can store the local URI of the image in your Room database.
	- Automatic Cloud Backup: Currently, users rely on manual JSON exports to save their data. Implementing an automatic, silent background backup to Google Drive (using the Google Drive REST API and WorkManager) would be a massive upgrade. You could add a toggle in Settings for "Auto-backup daily" so users never have to worry about losing their data if they lose their phone.
	- Enhanced Analytics & Trends (Line Charts): The current dashboard uses Donut charts for a great monthly snapshot. Adding Line Charts or Bar Charts to show Month-over-Month comparisons or Net Worth over time would give users a macro-level view of their financial health. You can easily implement these using a Compose-native charting library like Vico or YCharts.
	- Add a button at the bottom of the budget page to copy the budgets from last month which should all the un-set budgets for the current month.
	- Build calculator in amount section
	- Create pages for every type of settings in settings
	- Advanced Search & Filtering: As the database grows over the months, finding old entries gets difficult. A dedicated global search screen would be a lifesaver. Users should be able to type a keyword (like a friend's name, or a specific note like "wedding gift" or "lime sulfur dip") and filter the results by date range, category, or amount (e.g., "Show me all expenses over ₹5,000 last year").
